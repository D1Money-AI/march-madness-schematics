# March Madness 2026 — total points preview

Install dependencies (`pip install -r requirements.txt`), then run `python build_predictions.py` to regenerate `march_madness_totals_2026.html` from `NCAA_Mens_Tournament_2026_Complete_Results.csv`. Open the HTML file in your browser (double-click or drag into a tab).

Run `python fetch_multibook_lines.py` to refresh DraftKings lines from ESPN and optional multi-book odds (`ODDS_API_KEY` for The Odds API) into the CSV before rebuilding the HTML.
