MULTI-BOOK LINES (script: python fetch_multibook_lines.py)
- DraftKings full-game spread and total: pulled from ESPN’s game summary “pickcenter” for NCAA tournament games (group 50, season type 3). ESPN labels the provider as Draft Kings; it is not the same as BetMGM.
- Optional: set environment variable ODDS_API_KEY (The Odds API, basketball_ncaab) to merge live odds from draftkings, fanduel, betmgm, williamhill_us, betrivers, wynnbet, espnbet, bovada, lowvig, mybookieag. Completed games usually drop off the live feed; ESPN remains the practical backfill for those.
- Circa Sports is often not exposed on public odds APIs; Circa columns may stay empty unless you paste lines manually or use a vendor that carries them.
- “Market Over/Under” = median of all numeric totals present among MGM Over/Under and the filled book columns. “Market Point Spread” = MGM/BetMGM when set (including pk); otherwise first numeric spread from the priority list.
